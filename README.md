# シナリオ組版台

TRPG のシナリオを **書きながら、そのまま本の形に組む** ための道具です。

HTML ファイルが 1 つあるだけで動きます。インストールも、アカウント登録も、
サーバーとのやりとりもありません。原稿はあなたの手元から出ません。

左に原稿、右に紙面。打った字がそのまま、A4 の組み上がりとして隣に出ます。

![画面](docs/screenshot.png)

---

## 使いかた

### ブラウザでそのまま開く

**<https://sedn14636361.github.io/trpg-scenario-editor/>**

開くだけで使えます。原稿はこのページを開いたブラウザの中にだけ置かれ、どこにも送られません。

> シナリオの置き場は「どこから開いたか」で分かれます。ダウンロードしたファイルで書いたシナリオは、
> この Web 版の一覧には出ません（逆も同じです）。移すときは、元の側で **保存**（`.json`）して、
> もう一方で **シナリオ** の画面の **JSONを読み込む** を使ってください。

### ダウンロードして使う

1. [`trpgscenarioeditor.html`](trpgscenarioeditor.html) を右クリックして保存する
   （または画面上の緑の **Code** → **Download ZIP**）
2. 保存したファイルをダブルクリックして、ブラウザで開く

それだけです。ローカルサーバーも、ビルドも要りません。

推奨ブラウザは **Chrome / Edge**（Chromium 系）です。Firefox・Safari でも書けますが、
印刷の改ページの位置がずれることがあります。

## できること

### 画面の並び

左から **書式ツールバー・原稿・紙面・プロパティ等** の順に並びます。
原稿と紙面をできるだけ広く取り、たまにしか触らない設定は奥にしまってあります。

| 場所 | 内容 |
|---|---|
| 左：書式ツールバー | 書式のアイコン。押すと内容が開き、もう一度押すと閉じる。`«` で細い帯にしまえる |
| 左下：ドキュメント設定／ページ一覧 | ツールバーのいちばん下のアイコン。押すと原稿欄の左に引き出しが開き、もう一度押すと閉じる |
| 右：段落の設定 | 段落を選んでいるときだけ出る。右上の `×` か `Esc` で閉じる（選択が外れる）。選んだ段落の設定と、段落の操作（上へ・下へ・複製・削除など） |

境目をつかむと原稿・紙面・プロパティ等の幅が変わります。

### 段落の書式

左の書式ツールバーで選びます。関連の近い書式を 1 つのアイコンにまとめてあり、
押すと内容が横に開きます。`Ctrl` + `Shift` + 下のキーでも切り替わります。

| アイコン | 書式 | キー |
|---|---|---|
| 本文ブロック | 描写 / 特殊（会話・注釈・情報は特殊ブロックのテンプレ） | `0` `6` |
| 見出しブロック | 見出し1〜3 / シーン移行 | `1` `2` `3` `8` |
| 区切りブロック | 罫線 / 縦線 / 改ページ / 改段 | `H` `V` `B` `D` |
| 図表ブロック | 画像 / 表 / フローチャート | `G` `X` `F` |
| シートブロック | NPCシート / ハンドアウト | `9` `Y` |
| 新規ウィンドウの追加 | 新規ウィンドウ | `W` |
| 装丁ブロック | 表紙 / 目次 / 奥付 | `C` `M` `K` |
| 表題ブロック | タイトル / サブタイトル | `T` `S` |

罫線・縦線・改ページ・改段・目次・画像・フローチャート・表・NPCシート・新規ウィンドウは段落の文字を使わないので、
文字の書いてある段落を選んでいるときは、その段落を変えずにすぐ下へ新しく足します。
選んでいる段落が空っぽなら、その段落が変わります。
画像・表・NPCシート・目次・改ページなど文字を打てない段落を選んでいるときは、どの書式を選んでも、
それを作り変えずにすぐ下へ新しい段落を足します（画像の選び直しは右の設定欄で）。

「特殊」（前の名前は「処理」）は、判定・ルール・会話・注釈をまとめた書式です。
テンプレ（技能判定・特殊ルール・会話・注釈）を選ぶか、枠線の形・左の罫（なし・細い・太い）・字の大きさ・
地色・文字にも色・色（朱・墨・紺・藍・苔・金茶・灰）を選べます。
見出し（会話なら話し手）は、原稿欄の本文の上の欄でも打てます。会話のテンプレでは見出しの欄が話し手になります。会話・注釈・情報は書式ツールバーには出さず、テンプレか `:::dialog` `:::note` `:::info` で作ります。
枠をなしにしても、地色か左の罫があれば文字との間に左右の余白をとります。
前の版の会話・注釈は、開いたときに見た目を写して特殊ブロックへ読み替えます。

### 段落の中の段落

**どの段落も、中に段落を入れられます。** 原稿欄で `Tab` を押すと、その段落が **すぐ上の段落の中** へ入り、
`Shift` + `Tab` で外へ出ます。何段でも入れ子にでき、原稿欄では中の段落の範囲を **金の縦線** で示します。

- 中に段落を持てるのは、描写・特殊・情報・ハンドアウト・シーン移行。
  紙面では、枠のある書式は枠の中、`■` のかたまりは左の罫線の内側、ほかは一段（4mm）下げて並ぶ
- すぐ上が見出し・タイトル・画像・表など中に段落を持てない書式のときは、`Tab` は今までどおり字下げ
- 中に段落を持つ段落の末尾で `Enter` を押すと中の先頭に、中のいちばん後ろの空の段落で `Enter` を押すと外へ
- 親の段落を消すと、中の段落もいっしょに消える。中に段落を持つ段落はひとかたまりでページをまたげない

特殊ブロックの中も同じしくみです。特殊ブロックの文章の末尾で `Enter` を押すと、中に段落ができます。

```
■成功
天板の裏に呪詛が刻まれていることがわかる。
```

のように小見出し（`■`）で始めると、その段落は（特殊ブロックの中でも外でも）**左に罫線のついたかたまり** になります。
かたまりの中にも、`Tab` で判定などを入れられます。
小見出しの行の末尾の `Enter` は同じ段落の中の改行、本文の末尾の `Enter` は次のかたまりへ進みます。
中のいちばん後ろの空の段落で `Enter` を押すと、外へ出ます。
中の段落を「特殊」にすると、判定の入れ子（枠の中の枠）になります。
改ページ・目次・見出し1〜3・NPCシートなど、紙面の組みにかかわる書式は中に置けません。
前の版で特殊ブロック（前の名前は処理）の文章に書いた `■成功` や `＞目星：…` は、開いたときに一度だけ中の段落へ分け直します。

### 入れ子の書式（行の頭の印）

本文の中では、行の頭に印を置くと見た目が変わります。markdown と同じ書き方も通ります。

| 印 | なるもの | 打ちやすい合図 |
|---|---|---|
| `- ` | 箇条書き | `/kajou` `/list` |
| `1. ` | 番号つき | `/bangou` `/num` |
| `- [ ] ` | 選択肢（`- [x]` で済みの印） | `/sentaku` `/check` |
| `  - ` | 1つ内側の箇条書き | `/sagedan` `/indent` |
| `■`（`#### `） | 囲みの中の小見出し | `/midashi` `/head` |
| `◇`（`##### `） | ひとまわり小さい小見出し | `/komidashi` `/sub` |
| `※` | 注釈 | `/chushaku` `/note` |
| `> 技能：` | 判定の枠 | `/hantei` `/roll` |
| `「」` | 会話（`名前「…」`で話し手つき） | `/kaiwa` `/talk` |
| `｜項目｜内容｜` | 表 | `/hyou` `/table` |
| `＠` | 新規ウィンドウを開くボタン | `/betsumado` `/pop` |

`■` や `◇` は打つのが手間なので、行の頭で `/` を打つと **候補の一覧** が出ます。
`↑` `↓` で選んで `Enter` か `Tab` で入ります。続けて打つと絞り込めます
（`/ko` → 小見出し、`/みだし` → 見出し・小見出し）。日本語入力のままなら全角の `／` でも出ます。
`/komidashi` のように最後まで打って空白を押しても、その場で印に化けます。
化けたあとの原稿はふつうの印そのものなので、紙面・書き出し・表の出力・文字数のどれにも影響しません。

### markdown の書き方

見出し・罫線・画像は **markdown（CommonMark）と同じ書き方** です。
組版台だけの書式は、markdown の拡張としてよく使われる `:::` の囲み
（remark-directive・Pandoc・markdown-it-container と同じ形）で書きます。
**貼り付けると** 段落ごとに分けて取り込み、**描写の段落の頭で打っても** その書式に変わります。

| 書き方 | なるもの | 打ったとき |
|---|---|---|
| `# ` `## ` `### ` | 見出し1〜3（`#5` のように空白がなければ文字のまま） | 空白で変わる（`＃` と全角の空白でも） |
| `---` `***` `___` | 罫線（本文の行のすぐ下に書いても罫線） | Enter で変わる（`ーーー` でも） |
| `![説明](…)` | 画像（`data:image` の絵だけ入れる。外のアドレスは読みにいかない） | 貼り付けのみ |
| `:::名前[ラベル]{属性}` … `:::` | 囲み。中身ごとその書式になる。閉じがなければ最後まで | 1行目で Enter。カーソルは中へ |
| `::名前[ラベル]` | 中身のない1行の書式 | Enter で変わり、次の段落へ |

段落の頭で `::`（`：：`）か `#` を打つと **候補の一覧** が出ます（`/` の候補と同じ操作。紙面の上で直接打っているときも出ます）。
続けて打つと絞り込め（`::pa` → 改ページ、`：：かい` → 会話・改ページ・改段）、選ぶと段落がすぐその書式になります。

名前は英字が正式で、日本語の別名（`:::特殊` `::改ページ` など）や、日本語入力のままの `：：：` `［］` も通ります。
知らない名前は、書いたとおりの文字で描写に残ります。

| 名前 | なるもの |
|---|---|
| `:::proc[見出し]{tpl=rule}` | 特殊（`tpl` は `skill`・`rule`・自分で作ったテンプレの名前。`:::skill` `:::rule` とも書ける） |
| `:::info[見出し]` | 情報 |
| `:::handout[題]{no=HO2}` | ハンドアウト（`no` がなければ空いている番号） |
| `:::note` ／ `:::dialog[話し手]` | 特殊ブロックの注釈 ／ 会話のテンプレ |
| `:::popup[ボタン名]` | 新規ウィンドウ（中身もまた段落に分ける。外側を `::::` にすれば入れ子にできる） |
| `:::npc[名前]` | NPCシート（中身はメモ） |
| `:::flow` | フローチャート（1行が1つの箱、`- ` の行が分かれ道） |
| `:::table[表の名前]` | 表（中身は `\|1d6\|内容\|` の行） |
| `::scene[書斎へ]` `::title[…]` `::subtitle[…]` | シーン移行・タイトル・サブタイトル |
| `::pagebreak` `::colbreak` | 改ページ・改段 |
| `::vr` `::toc` `::cover` `::colophon` | 縦線・目次・表紙・奥付 |

```
# 第一章 洋館
雨の夜、館に着く。

:::proc[〈目星〉]{tpl=rule}
#### 成功
日記を見つける
:::

::pagebreak
```

`> ` は markdown では引用ですが、組版台では判定の枠のままです。
markdown の書き方が何もない1段落だけを貼ったときは、これまでどおりただの文字として入ります。

### 情報ブロックとハンドアウト

**情報** はプレイヤーに渡す情報をまとめる枠で、特殊ブロックのテンプレのひとつです。
特殊ブロックの **押すと本文をコピー** を ON にすると、出力した HTML で枠を **クリックするだけで本文** をコピーできるので、
セッション中にチャットへそのまま貼れます（情報のテンプレは、はじめから ON）。

**ハンドアウト** はハンドアウト番号（HO1）・ハンドアウト名・本文を持つ枠です。同じくクリックでコピーできます。
ハンドアウト番号はそのまま変数 `{HO1}` になります。

### 変数（`{HO1}` など）

本文などに `{HO1}` と書いておくと、**出力した HTML で入れた名前に置き換わります**。
HTML の左に「登場人物（変数）」の欄が出て、そこに「佐藤 千景」と入れれば、文中の `{HO1}` がすべてその名前になります
（入れた値はブラウザに覚えさせます）。

- `{HO1}` `{HO2}` のような **HO＋数字** は、ハンドアウトの枠がなくても書くだけで使えます
- それ以外の名前（`{KP}` など）は、左下の「ドキュメント設定」の **変数** の欄で登録したものだけが置き換わります。
  ココフォリアの `{SAN}` のような書き方は、登録しなければそのまま残ります
- ドキュメント設定の変数の欄で、すべての変数の名前・既定値・説明を直せます。ハンドアウトの変数は、ハンドアウトのプロパティでも直せます
- 編集画面の紙面でも、出力した HTML を開いた直後と同じ表示（既定値。なければ `HO1` のような名前）で見えます

### ルビ

`｜漢字《かんじ》` と書くと、ルビが振れます。`Ctrl` + `Shift` + `R` でも入ります。
見出し・会話・画像の説明文など、文字が出るところならどこでも使えます。

### 文字の大きさ

右の設定欄の **文字の大きさ** で、文字の色と同じ形で **pt を決められます**。
ボタン（8・10・12・14・18・24・36pt）を押すか、欄に好きな pt（5〜72pt、0.5pt きざみ）を書きます。
文字を選んでいればその文字だけ、選んでいなければ選んだ段落が変わります。
`Ctrl` + `Shift` + `>` / `<` では、Word と同じ並び（8・9・10・10.5・11・12・14・16・18・20・22・24・26・28・36・48・72pt）でひとつずつ動きます。

- 大きさは pt のまま持つので、ドキュメント設定の基準の文字の大きさを変えても動きません
- 段落の中の段落は、親と別に大きさを決めます（親を大きくしても中はそのまま）
- 色と大きさは重ねて付けられ、紙面・印刷・書き出した HTML のどれにも同じ大きさで出ます
- 選んだ範囲や段落の中で大きさが混ざっているときは、欄は「—」になり、どのボタンも光りません
- そのすぐ下の **この段落の上下の余白（mm）** で、段落ごとに上下の余白を決められます（空なら書式ごとの既定）
- v3.17〜v3.20 の倍率（%）で付けた大きさは、開いたときにその時の pt に読み替えます（0.5pt きざみに丸めます）

### 表

行と列を足し引きでき、升目の中に段落をそのまま入れられます（表の中に囲みや箇条書きが置けます）。
表からは **ココフォリアのロール表** の文字列も出せます。

### フローチャート

箱を置いて線でつなぐ、分かれ道つきの図です。Figma のように自由に配置でき、
箱の形（四角・角丸・ひし形・端子・入出力）、大きさ、二段分け、余白、色を選べます。
複数まとめて選んで、中央ぞろえ・横幅そろえ・余白均等がかけられます。

### 新規ウィンドウ

紙面には出さず、ボタンから開く補足のページを作れます。
NPC の裏設定、ハンドアウト、GM だけが読む注記などに使えます。
印刷と書き出しでは、巻末に「追記」としてまとめて付きます。
書き出した HTML では、ボタンを押すと本文の上に**浮かぶ窓**が開きます（背景は暗くならず、開いたまま本文を読める。動かす・大きさを変える・いくつも開ける）。
印刷・PDF では、ボタンの位置に「→ 追記」のリンク、追記の各節に「↩ P.3 へ戻る」のリンクが入ります。

### NPC シート

名前・肩書き・能力値・技能などをまとめた囲みです。立ち絵も置けます。
**ココフォリアのコマ**を貼り付けて読み込むことも、逆にコマとして書き出すこともできます。

### 目次

何を載せるか（タイトル・見出し1〜3・サブタイトル・シーン移行）を書式ごとに選べます。

シーン移行ブロックの行き先の名前（「書斎へ」「→ 書斎へ移行」など）が見出し1〜3とぴったり同じなら、書き出した HTML と PDF でその見出しへのリンクになります。
右の設定欄の **ジャンプする見出し** に見出しの名前を書けば、本文の書き方にかかわらずその見出しへジャンプします（候補から選べます）。
さらに見出し 1 つずつに、

- 目次に出る文字（見出し本体とは別に決められます）
- 載せる／載せない（書式ごとの設定を上書きします）
- 目次での段さげ

を持たせられます。ページ番号と点線は出し入れできます。

目次ブロックは **載せる範囲** を「全体」か「この章だけ」から選べます。「この章だけ」は、
すぐ上の見出し1から次の見出し1の手前までの見出しを載せるので、章ごとの細かい目次が作れます。
見出し1を選んで「装丁ブロック → 目次」を押すと、その章の頭に章の目次が入ります。

### 紙面

- ページごとに 1 段組／2 段組
- 余白（天地・左右）と基準の文字の大きさ
- 表紙ページと奥付ページ
- ノンブル（ページ番号）と柱（決まり文句）、始まりの番号
- 紙の色（ページごと。色のボタン10色・雰囲気からのおまかせ・好きな色。文字とのコントラスト比 7:1 を下回る色は自動で明るくする）。区切りなしの出力では、ページごとの色を上から順にグラデーションでつなぐ
- 背景の柄（無地・方眼・ドット・古紙・和紙・飾り枠・四隅の飾り・上下の帯）。本文の下はごく薄く、飾りは余白の中だけ。区切りなしの出力では画面や本文の欄に合わせて出す
- 画像（図表ブロック → 画像）。置き方は 行内・左に流す・右に流す・自由配置 の 4 つ
- 自由配置の画像は段落の並びとは別の層で、紙の左上から画像の左上までの座標（mm）で置く。紙面で画像を押すと右の欄に設定が出る。本文の範囲の四隅に合わせるボタン付き。本文の文字はいつも避け、文字との間隔（上下・左右、mm）を画像ごとに決められる。区切りなしの出力でも本文の始まりを基準に同じ位置関係で出す
- 画像の枠（なし・細線・太線・二重線と 6 色）と影（なし・薄い・ふつう・濃い）。枠は画像の上に重ねるので大きさは変わらない。透明な画像の影は絵の形に沿う
- 画像の幅は ％（本文の幅に対して）と px（96px＝25.4mm）をラジオボタンで選べる
- ページ一覧（`Ctrl` + `Shift` + `P`）。左の引き出しに 1 ページずつ出し、`▲` `▼` で切り替える。そのページの見出しも並び、押すとそこへ飛ぶ

## 保存と書き出し

| | |
|---|---|
| **自動保存** | 打つたびにブラウザの中に控えます（打ち終えて 0.7 秒、打ち続けていても 3 秒ごと）。閉じても次に開けば続きから |
| **シナリオ** | シナリオをいくつでもブラウザの中に置いておけます。一覧から開く・新しく作る・JSONを読み込む・複製・過去の版・削除（ゴミ箱） |
| **保存 ▾** | 保存先を選べます。**ブラウザに保存** は、いまの姿に名前を付けてシナリオの「過去の版」に★として残します（自動の版に押し出されず、通信もしません）。**JSONファイルに保存**（`Ctrl` + `S`）は下のとおりです |
| **JSONファイルに保存**（`Ctrl` + `S`） | `.json` ファイルとして手元に残します。これが原稿の本体です。Chrome / Edge では以後、自動保存のたびにそのファイルにも書きます |
| **印刷 / PDF** | ブラウザの印刷画面から PDF にできます |
| **HTML** | 配布用の**閲覧 HTML** を 1 ファイルで出力します。渡された人は開くだけで読めます。形式は **ページごと**（A4 を並べる。目次から飛ぶとそのページの頭から見える）か **区切りなしの1枚**（画面ぜんたいが紙。目次・章の目次・新規ウィンドウへ飛んで「↩ 戻る」で戻れる）を選べます |

起動するとシナリオの一覧が出ます。最後に開いていたシナリオが選ばれているので、
そのまま **開く**（または `Enter`）で続きから書けます。

### 原稿を失わないために

| しくみ | 守るもの |
|---|---|
| 閉じる瞬間の控え | タブを閉じる・再読み込みする瞬間に保存しきれなかった分を控え、次に開いたときに戻します |
| 3 秒ごとの保存 | 打ち続けていても 3 秒ごとに書くので、ブラウザがいきなり落ちても、消えるのは最後の数秒分までです |
| 1 シナリオ 1 タブ | 同じシナリオは 1 つのタブでしか開けません（「別のタブで編集中」）。2 つのタブで上書きし合うことがありません |
| 過去の版 | シナリオごとに、開いたとき・書いているあいだ 10 分ごと・「全部消して最初から」の直前の姿を 10 個まで残します |
| ゴミ箱 | 削除したシナリオは 30 日のあいだ戻せます |
| 失敗の帯 | 保存に失敗すると、画面の上に赤い帯が出て、直るまで消えません |
| ファイルへの自動保存 | Chrome / Edge では、はじめの **保存** で選んだファイルにも自動で書きます。ブラウザのデータが消えても、そのファイルから戻せます |

> シナリオはブラウザの IndexedDB に置きます。ブラウザのデータを消すとシナリオも消えるので、
> 大切な原稿は **保存** でファイルにも残してください（Chrome / Edge なら一度選べば以後は自動です）。
>
> v3.1 までの自動保存は、はじめて v3.2 以降を開いたときにシナリオとして引き継ぎます。
> 引き継いだあとは古い保存場所から消すので、古い版の組版台ではその原稿が見えなくなります
> （消す前に確認が出ます）。
>
> IndexedDB が使えないブラウザでは、これまでどおり 1 シナリオだけを保存します。
> その場合は画像やフォントで自動保存の容量（4MB）を超えることがあり、画面下に知らせが出ます。

## 内容について

- 素の HTML / CSS / JavaScript だけで書かれた **1 ファイル**です。
  ビルドも、外部のライブラリも、通信もありません。
- 紙面の見た目を決める CSS は `DOC_CSS`（JavaScript の中の文字列）に集めてあり、
  編集画面と書き出し HTML の両方がこれを使います。だから**画面と書き出しが食い違いません**。
- フローチャートは、形と線を SVG で、文字を mm 指定の HTML で重ねて描いています。
- コメントは日本語で、「なぜそうしたか」を残す形で書いてあります。

直したいところがあれば、ブラウザで開いてそのまま読めます。
